# App_Enedis

Projet d'étude sur l'électricité en réseau.

## Installation

```powershell
python -m venv .env-enedis
.\.env-enedis\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Contribution

Le projet est développé en équipe. Toute modification doit partir d'une
Issue, être réalisée sur une branche dédiée, puis être proposée par Pull
Request. Consultez [CONTRIBUTING.md](CONTRIBUTING.md) avant de commencer.

La branche `main` est réservée au code validé. Les changements doivent passer
par une Pull Request et une revue de code.
